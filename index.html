Proyecto integrador listo para presentación

El backend ya responde con rutas REST y la interfaz ya está conectada. Puedes entrar como docente o como alumno y simular actividad del módulo IoT.

Lo que ya quedó implementado

Backend + CSS + conexión frontend con endpoints.

Autenticación por rol Redirige a vista docente o alumno.
Dashboard docente Muestra alumnos, estado de módulo, métricas y SOS.
Panel alumno Muestra actividad, tareas, progreso y audio.
Modo demo No depende de MySQL para funcionar localmente.

Endpoints principales

Listos para pruebas en Postman o fetch.

POST /api/auth/login

Autenticación con usuario o correo y contraseña.

GET /api/docente/dashboard

Resumen global del grupo y estado del backend.

GET /api/alumno/:id/resumen

Resumen del alumno, actividad, tareas y métricas.

POST /api/alumno/:id/sos

Dispara una alerta para el panel docente.
